================================================================================
Water-Smart Crop Planner — Raw Data Column Descriptions
Study district : Tiruvallur, Tamil Nadu, India (13.14 N, 79.91 E)
Years covered  : 2010–2023
================================================================================

All five CSV files follow the same conventions:
  • UTF-8 encoding, comma-separated.
  • Header row in row 1.
  • Dates in ISO-8601 format (YYYY-MM-DD) or year as 4-digit integer.
  • Numeric missing values encoded as empty string "" or NaN (not -999 after
    cleaning; -999 is a NASA POWER sentinel and is converted to NaN on ingest).
  • Files generated by generate_synthetic.py start with the comment line:
      # SYNTHETIC DATA — generated by generate_synthetic.py — NOT real observations
  • Files that include Kancheepuram district rows carry source="merged" in the
    source column.

────────────────────────────────────────────────────────────────────────────────
1. weather.csv
────────────────────────────────────────────────────────────────────────────────
Source : NASA POWER Community "Ag" API (https://power.larc.nasa.gov/)
         OR generate_synthetic.py
Grain  : One row per calendar day per district.

Column              Type     Unit            Description
──────────────────  ───────  ──────────────  ─────────────────────────────────────
date                date     YYYY-MM-DD      Calendar date
PRECTOTCORR         float    mm/day          Precipitation (bias-corrected)
T2M_MAX             float    °C              Daily maximum 2-m air temperature
T2M_MIN             float    °C              Daily minimum 2-m air temperature
RH2M                float    %               Relative humidity at 2 m
WS2M                float    m/s             Wind speed at 2 m
ALLSKY_SFC_SW_DWN   float    MJ/m²/day       All-sky surface shortwave downwelling
                                             irradiance (solar radiation)

Notes:
  • NASA POWER sentinel value -999 is converted to NaN during fetch.
  • Rows with NaN in PRECTOTCORR or T2M_MAX/T2M_MIN are forward-filled
    (≤ 3 consecutive days) then flagged in the validation log.
  • Solar radiation is used as a proxy for photosynthetically active
    radiation in ET₀ estimation; not used directly in current model features.

────────────────────────────────────────────────────────────────────────────────
2. yield.csv
────────────────────────────────────────────────────────────────────────────────
Source : Dept. of Agriculture Tamil Nadu / data.gov.in district crop statistics
         OR generate_synthetic.py
Grain  : One row per (year, season, crop, district).

Column              Type     Unit            Description
──────────────────  ───────  ──────────────  ─────────────────────────────────────
year                int      YYYY            Harvest year
season              str      —               kharif | rabi | summer
crop                str      —               paddy | groundnut | sugarcane |
                                             black_gram | green_gram | maize | ragi
district            str      —               Tiruvallur | Kancheepuram
yield_kg_ha         float    kg/ha           District-average crop yield
area_ha             float    ha              Sown area (optional; used for
                                             dominance calculation in backtest)
source              str      —               "real" | "merged" | "synthetic"
                                             "merged" = Kancheepuram row added to
                                             Tiruvallur series for years ≤ 2019

Notes:
  • Rows with yield_kg_ha ≤ 0 or area_ha ≤ 0 are treated as missing.
  • Crops with fewer than config.crops.min_data_years (default 8) usable
    rows after cleaning are dropped from candidate list.

────────────────────────────────────────────────────────────────────────────────
3. prices.csv
────────────────────────────────────────────────────────────────────────────────
Source : Agmarknet / Koyambedu mandi reports
         OR generate_synthetic.py
Grain  : One row per (year, month, crop, market).

Column              Type     Unit            Description
──────────────────  ───────  ──────────────  ─────────────────────────────────────
year                int      YYYY            Calendar year
month               int      1–12            Calendar month
crop                str      —               Same crop codes as yield.csv
market              str      —               e.g. Koyambedu, Tiruvallur
price_inr_quintal   float    ₹/quintal       Wholesale modal price
                                             (1 quintal = 100 kg)
source              str      —               "real" | "synthetic"

Notes:
  • Price is converted to ₹/kg internally: price_inr_kg = price_inr_quintal / 100.
  • Months with price_inr_quintal ≤ 0 are treated as missing.
  • Monthly prices are aggregated to seasonal averages for the price model.

────────────────────────────────────────────────────────────────────────────────
4. crop_water.csv
────────────────────────────────────────────────────────────────────────────────
Source : FAO-56 crop coefficients + TNAU reference ET₀ estimates
         OR generate_synthetic.py
Grain  : One row per (crop, season).

Column              Type     Unit            Description
──────────────────  ───────  ──────────────  ─────────────────────────────────────
crop                str      —               Same crop codes as yield.csv
season              str      —               kharif | rabi | summer
water_req_mm        float    mm/season       Total seasonal crop water requirement
                                             (ETc = Kc × ET₀ integrated over
                                             growing period)
growing_days        int      days            Approximate growing period length
kc_mid              float    —               FAO-56 mid-season crop coefficient
source              str      —               "fao56" | "tnau" | "synthetic"

Notes:
  • water_req_mm is the total consumptive water use per season, not irrigation
    requirement; actual irrigation need = max(0, water_req_mm − rainfall).
  • Values are treated as fixed per crop-season; inter-annual variation is
    captured via the rainfall deficit term in the optimisation objective.

────────────────────────────────────────────────────────────────────────────────
5. cost.csv
────────────────────────────────────────────────────────────────────────────────
Source : TNAU Cost-of-Cultivation Bulletins (annual)
         OR generate_synthetic.py
Grain  : One row per (year, crop, season).

Column              Type     Unit            Description
──────────────────  ───────  ──────────────  ─────────────────────────────────────
year                int      YYYY            Reference year for cost estimates
season              str      —               kharif | rabi | summer
crop                str      —               Same crop codes as yield.csv
cost_inr_ha         float    ₹/ha            Total input cost per hectare
                                             (seed + fertiliser + labour +
                                             irrigation + machinery)
source              str      —               "tnau" | "synthetic"

Notes:
  • Costs are in nominal terms (not inflation-adjusted).
  • When no cost record exists for a given (year, crop, season), the most
    recent available year's cost is forward-filled with a WARNING logged.

────────────────────────────────────────────────────────────────────────────────
Sentinel Values & Encoding Conventions
────────────────────────────────────────────────────────────────────────────────
  • -999   : NASA POWER missing-data sentinel; converted to NaN on ingest.
  • NaN    : Standard pandas/NumPy missing value after cleaning.
  • ""     : Empty string in raw CSV; treated as NaN during loading.
  • "real" / "synthetic" / "merged" : source column values across all files.
  • Crop names use underscores (black_gram, green_gram) matching config.yaml.
  • Season names are lowercase: kharif, rabi, summer.
  • District names: Tiruvallur, Kancheepuram (title-case).

================================================================================
Data Limitations
================================================================================
  • District-level aggregates mask within-district spatial variability.
  • Yield data gaps may exist; the 2019 district split affects Tiruvallur
    records (use merge_kancheepuram: true in config to extend the series).
  • Synthetic data is statistically plausible but does NOT represent real
    historical observations; models trained on it are for development only.
  • Price data reflects wholesale markets; farm-gate prices may differ.
  • All outputs from models trained on this data are indicative estimates.
